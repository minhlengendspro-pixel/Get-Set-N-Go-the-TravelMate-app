Mô tả chi tiết các trường dữ liệu:

Trường Kiểu dữ liệu Bắt buộc Ý nghĩa & Hướng dẫn dành cho Backend / Frontend
id String Có Mã định danh duy nhất (P001 – P315). Dùng làm React key khi render.
name String Có Tên địa điểm chính thức. Dùng hiển thị tiêu đề thẻ (Card Title).
destination String Có Tỉnh/Thành phố trực thuộc. Dùng để Backend query lọc theo tỉnh thành.
category String Có Thể loại chung (sightseeing, culture...).
description String Có Đoạn văn mô tả đã làm giàu từ Kaggle. Hiển thị chi tiết bài viết.
rating String Có Đánh giá của du khách (ví dụ: 4.8/5).
image String Có URL ảnh minh họa chất lượng cao.
tags Array[String] Có Mảng từ khóa đặc trưng chuẩn hóa. Input cốt lõi cho Cosine Similarity & Bộ lọc UI.

III. HỆ THỐNG PHÂN TẦNG NHÃN (TAG TAXONOMY)

Toàn bộ 315 điểm đến được thiết kế theo cấu trúc nhãn phân tầng chặt chẽ:

1. Nhãn Tỉnh / Thành: hà nội đà nẵng khánh hòa hưng yên lâm đồng...
2. Nhãn Địa hình (Cơ sở): biển đảo núi rừng sông nước làng quê & đồng bằng đô thị
3. Nhãn Thể loại (Chính): thiên nhiên văn hóa - lịch sử nghỉ dưỡng ẩm thực vui chơi giải trí
4. Nhãn Ẩm thực (Đặc sắc): hải sản tươi sống đặc sản địa phương cà phê & trà ẩm thực đường phố
5. Nhãn Trải nghiệm: tắm biển & lặn ngắm san hô leo núi & trekking ngắm hoàng hôn & bình minh check-in sống ảo kiến trúc & di tích cổ lễ hội dân gian

IV. HƯỚNG DẪN TRUY VẤN MẪU CHO BACKEND DEVELOPER

# Python - PyMongo Query Example
import pymongo

client = pymongo.MongoClient(MONGO_URI)
db = client["get_set_n_go_db"]

# Lọc các địa điểm tại Khánh Hòa và ẩn trường _id
places = list(db.Places.find(
    {"destination": {"$regex": "^Khánh Hòa$", "$options": "i"}},
    {"_id": 0}
))

print(f"Tổng số địa điểm: {len(places)}")
